# Dashboard UI Override

Use the master system with a slightly denser operational layout.

## Density
- Desktop dashboard section gaps: 16–24px.
- KPI card padding: 20–24px.
- Primary chart/data surfaces: 24–32px internal padding.
- Mobile: collapse to one column and prioritize current status/tasks before historical analytics.

## Hierarchy
Header → KPI summary → primary operational/analytic surface → secondary insights → recent activity/actions.

## KPI cards
Use four or fewer top-level KPIs at desktop width. Every card must identify the metric, current value, and what action/view it leads to.

## Charts
Prefer one primary insight per chart. Keep legends and tooltips readable, avoid decorative chart effects, and preserve an accessible textual interpretation for important metrics.

## Interaction
Refresh and export actions must have visible loading/disabled states. Cards that navigate should communicate clickability without requiring hover.
